# Shopcontrols — система управління магазином

Вебзастосунок для магазину з кількома відділами: каталог і архів товарів, закупівельні ціни постачальників, залишки, постачання, продажі та комбіновані оплати. У «Менеджери» можна вибрати профіль без пароля й змінити ім’я.

**Стек:** C# / .NET 10, ASP.NET Core **Razor Pages**, Npgsql, PostgreSQL, Bootstrap. Repository + Unit of Work об’єднує операції в транзакції; читання БД відбувається через представлення, зміни - через збережені процедури.

БД - store.dbml, Untitled.pdf
